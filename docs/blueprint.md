# **App Name**: N8N Agent Interface

## Core Features:

- Webhook Display: Display the webhook URL clearly for easy access and configuration: https://luis-epico.app.n8n.cloud/webhook-test/input.
- Dynamic Form Generation: Create a form to send data to the N8N workflow through the webhook. The form fields should dynamically adjust based on the expected input from the workflow.
- Response Display: Display the response received from the N8N workflow in a clear and user-friendly format.

## Style Guidelines:

- Primary color: Deep blue (#1A237E) for a professional and reliable feel.
- Secondary color: Light purple (#E1BEE7) to complement the blue and add a touch of creativity.
- Accent: Teal (#00ACC1) for interactive elements and highlights.
- Modern, clean layout with clear sections for webhook information, input form, and response display.
- Use simple, professional icons to represent different actions and data types.
- Subtle animations for loading states and form submissions to improve user experience.
